# Portfolio scope and disclosure

This repository contains public demonstration work created to show current practical capabilities.

- **Demonstration projects** use fictional or synthetic inputs and are labelled clearly.
- **Client work** will only be included with appropriate permission and/or full anonymisation.
- **Private projects** remain private unless they are deliberately prepared and approved for public release.
- AI-assisted tools may be used during development. Published outputs remain subject to explicit validation and acceptance checks.
- No credentials, private datasets, client secrets or proprietary source code should be committed to this repository.
